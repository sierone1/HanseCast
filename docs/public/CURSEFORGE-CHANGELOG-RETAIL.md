# Hanse Cast 1.0.8 – Retail

First Retail release, built from the shared Hanse Cast code with isolated Retail settings and compatibility checks.

- Separate spell catalog for all 13 Retail classes and first-run artwork mappings for 40 specializations. Additional class categories reuse shipped artwork.
- Fresh settings select specialization artwork and enable safe Blizzard player-bar replacement. Optional per-spell artwork starts disabled; existing preferences are preserved.
- Player casting, channels, GCD, profiles and compact target/focus bars use supported API paths. Restricted player timing retains Blizzard.
- Empower is handled by Blizzard, including target/focus fallback when Empower flags are inaccessible or channel metadata fails. No custom Empower stages.
- Full installation, settings, troubleshooting and limitation documentation included.

For Retail 12.1.5 / Mainline interface 120105 only. General in-game testing of alpha.2 confirmed by the user. Final version/status metadata and documentation updated; runtime behavior unchanged. Other interfaces are deliberately rejected. Fully restart WoW after updating; do not use the Forever package in Retail.
