# Hanse Cast

Animated player cast bars and compact target/focus bars, with separate downloads for **WoW Forever 1.60.1** and **WoW Retail 12.1.5**.

## Choose the right file

- **Forever:** Hanse Cast 1.0.8 – Forever. Interface 16001; compact target/focus bars support builds 70862 and 70888.
- **Retail:** Hanse Cast 1.0.8 – Retail. Mainline interface 120105. Do not install the Forever package in Retail or both packages into the same client.

## Player cast bar

Choose from five artwork families: Element Stream, Splinters & Sparks, Silk Flow, Pulse and Mistlight. Customize size, position, fonts, spell icons and time display. Class-inspired and Alliance/Horde artwork can be selected independently of your character's class. Retail class categories reuse existing shipped materials; they are not an additional set of unique paintings.

On a fresh installation with no saved settings, Hanse Cast selects artwork for the current class and specialization. Forever can use the talent tree with the most invested points. If specialization data is unavailable, a class default is used. Settings are account-wide: this is a one-time initial selection, not automatic profile switching whenever you change characters or talents.

Optional **per-spell artwork** is off by default. Enable it to temporarily select artwork for recognized, readable cast/channel spell IDs, such as Shadow, Holy or Discipline priest spells. Unknown or restricted IDs keep your selected artwork. Instant abilities do not create artificial cast bars.

Safe Blizzard player-bar replacement is enabled for fresh settings. Blizzard is hidden only while Hanse Cast can provide the active display; unavailable data or artwork retain the default bar. Updates preserve your existing preferences.

Includes a separate GCD indicator, reduced motion, favorites and up to twelve named player profiles with copy, rename and text import/export. Channel guides are manual aids, not automatic tick detection.

## Target and focus

Three compact designs, a shared color picker, separate positions, adjustable dimensions and fonts, and optional remaining time inside or outside the right edge. A dash indicates unavailable time data. Blizzard target/focus replacement is configured separately. Compact settings are shared independently of player profiles.

No extra pet, target-of-target or nameplate bars. Selected pets can still be displayed as your target or focus.

## Retail limits

The animated player bar requires readable timestamps. Restricted player timing and empowered spells retain Blizzard's cast bar. Compact target/focus bars hand duration objects to native widgets; Empower, inaccessible Empower flags and failed channel queries retain Blizzard. There is no custom Empower-stage display. Only the specified client interface is enabled; future patches may require an update.

## Install and use

Install the matching file through CurseForge or extract its `HanseCast` folder into the correct client's `Interface/AddOns`. Fully restart WoW after updating. Keep saved settings; disable the obsolete standalone Hanse Cast Compact Lab if present. No additional addon or runtime library is required.

- `/hansecast`: settings, player appearance, profiles and help.
- `/hccompact`: target/focus settings.
- `/hansecast test`: toggle player preview.
- `/hansecast status`: version and status.
- `/hansecast report`: copyable diagnostics.

Configuration changes are blocked in combat. German and English UI are available. Retail and Forever store preferences separately. A player profile export is not a complete backup of compact settings.

# Deutsch

Animierte Spieler-Zauberleisten und kompakte Ziel-/Fokusleisten für **Forever 1.60.1** und **Retail 12.1.5**, jeweils als eigenes Paket. Für Forever nur die Forever-Datei auswählen, für Retail die Retail-Datei. Beide gehören in den Ordner `HanseCast` des jeweiligen Clients.

Fünf Grafikfamilien, anpassbare Position, Größe, Schrift, Symbol und Zeitdarstellung, separate GCD, ruhiger Modus, Favoriten und bis zu zwölf Spielerprofile stehen bereit. Die zusätzlichen Retail-Klassen nutzen vorhandene Materialien.

Ohne gespeicherte Einstellungen wird beim ersten Login eine passende Klassen-/Spezialisierungsoptik gewählt; Forever berücksichtigt alternativ investierte Talentpunkte. Die Einstellungen sind kontoweit und wechseln später nicht automatisch mit Charakter oder Skillung. „Optik nach Zauber“ ist optional und zunächst aus. Aktiviert wählt sie für bekannte, lesbare Cast-/Kanal-IDs vorübergehend die passende Optik. Unbekannte/geschützte IDs behalten die Grundoptik.

Die Blizzard-Spielerleiste wird bei frischen Einstellungen ausgeblendet, solange Hanse Cast den aktuellen Zauber sicher darstellen kann. Vorhandene Einstellungen bleiben bei Updates erhalten. Ziel/Fokus haben eigene Ausblendoptionen, drei Designs, Farbauswahl, getrennte Positionen und optionale Restzeit. Ihre Einstellungen gehören nicht zu den Spielerprofilen.

Retail: Geschützte Spielerzeiten und Empower verwenden Blizzard. Auch Ziel/Fokus behalten bei Empower, unlesbaren Merkmalen oder Abfragefehlern die Standardanzeige. Keine eigene Empower-Stufenanzeige, keine automatischen Kanalticks, keine zusätzlichen Namensplakettenleisten. Forever-Kompaktleisten erlauben Builds 70862/70888; Retail ausschließlich Interface 120105.

Nach dem Update WoW vollständig neu starten. `/hansecast` öffnet die Einstellungen, `/hccompact` Ziel/Fokus, `/hansecast test` die Vorschau und `/hansecast bericht` die Diagnose. Änderungen im Kampf sind gesperrt. Das alte separate Compact Lab wird nicht benötigt.

Beide Varianten wurden vom Nutzer allgemein im Spiel bestätigt; eine vollständige Einzelprüfung aller Klassen und Zauber wird nicht behauptet. Grafiken entstanden mit KI-Unterstützung und lokaler Bearbeitung. Software-Vorschauen sind entsprechend gekennzeichnete Illustrationen.
